# My MERN Frontend

React frontend for My MERN Project.

## Run locally
1. Install deps
   npm install

2. Development
   # CRA
   npm start

   # or Vite
   npm run dev

3. Build (production)
   npm run build

## Environment variables
- REACT_APP_API_URL (or VITE_API_URL) — backend API base URL

## Notes
Do NOT commit .env or secrets.
